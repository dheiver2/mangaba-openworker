Este repositório hospeda os **downloads oficiais e a página** do Mangaba.

**[⬇️ Baixar a versão mais recente](https://github.com/dheiver2/mangaba-openworker/releases/latest)** · [Página de downloads](https://dheiver2.github.io/mangaba-openworker/)

- **macOS** (Apple Silicon): `.dmg` — ou `brew tap dheiver2/mangaba && brew install --cask mangaba`
- **Windows** (x64): `.exe` — SmartScreen na primeira execução é esperado ("Mais informações" → "Executar assim mesmo")

O app se atualiza sozinho. Cada release publica checksums SHA-256 e assinatura minisign, e o
instalador do Windows é testado automaticamente numa máquina Windows real antes de ser anunciado.

### O aviso de "app inseguro" na primeira instalação

Não é vírus: Windows e macOS mostram esse alerta para qualquer app novo de desenvolvedor
independente ("não conheço este publicador"). **Windows**: Mais informações → Executar assim
mesmo. **macOS**: clique direito no app → Abrir (assinado com Developer ID desde a v0.1.49).
Baixe somente deste repositório.
